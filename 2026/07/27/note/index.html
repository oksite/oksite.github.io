NOTEYOU：一款本地优先的 Markdown 编辑器

Posted on 2026-07-27 In 产品介绍

NOTEYOU 是什么？

NOTEYOU 是一款基于 Tauri 2 + Next.js 15 + CodeMirror 6 构建的
本地优先 Markdown 桌面编辑器。无账号、无云端、无独立数据库，
所有文档以普通 .md 文件保存在本地应用数据目录中。

✨ 核心特性

  • 🌲 树形文件管理，本地文件夹一目了然
  • ✏️ CodeMirror 6 编辑 + 语法高亮
  • 🗂 多标签、编辑/分栏/预览三视图
  • 💾 停止输入 1.2 秒自动保存
  • 🌓 亮色/暗色主题，同步 Windows 原生标题栏

🛠 技术栈

层级 技术
桌面壳 Tauri 2 / Rust
前端 Next.js 15 / React 19 / TypeScript
编辑器 CodeMirror 6
Markdown marked + DOMPurify
